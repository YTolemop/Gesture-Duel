# 主機與課前部署

此產品只部署在一台本機主機，其他玩家透過區網連入。每個壓縮包可獨立解壓；不要複製別台筆電的node_modules或.venv。依賴安裝需要外網，活動執行的網站、模型及圖片都在本機。

1. 主機安裝Node22.19.0 x64／npm10.9.3，解壓gesture-arena，執行setup_windows.bat。學員安裝Python3.13.2 x64，解壓gesture-player，執行setup_windows.bat。
2. 主機執行start_windows.bat，先用localhost:3000確認首頁、技能圖鑑與鍵盤練習。一般活動不要開ENABLE_INTERNAL_TEST_MODE。
3. 主機確認實體網卡IP。另一台筆電用該IP與3000埠，不能填localhost。Windows防火牆只新增此TCP埠的私人網路入站規則。以另一台筆電開網站確認；/health的成功不代表手勢配對成功。
4. 學員以run_windows.bat啟動GUI，選鏡頭，確認畫面、實際解析度／FPS及左右手槽。先錄原始樣本，再按docs/student_tasks.md填必要TODO、訓練並用獨立test批次評估。未完成TODO時可錄原始資料及測試工具，但不能正式宣稱手勢可用。
5. PVP由一人建立房間，其他人輸入房號按「加入房間」。房內可互換紅／藍／觀戰席，最多三人；觀戰可空缺。每位手勢玩家產生自己的配對碼，Python填主機網址、房碼與本人配對碼；也可選網站鍵盤。紅藍各一人且都準備後，自動倒數5秒進選技，紅方先選、每手30秒、逾時自選。選完再倒數5秒開戰，無需房主管理按鈕。
6. 活動前實際練習鏡頭故障：暫停、改本人來源為鍵盤、確認準備、恢復。失焦必須解除按鍵；不要用重設練習代替來源切換驗收。
   假人練習與一命連戰不顯示房號，每次建立獨立內部房間與狀態，不共用其他玩家的遊戲。單人Python配對只需主機網址與一次性配對碼，房碼留空；工具會保存伺服器回傳的內部房碼供自動重連。
7. 觀戰視窗移到HDMI外接顯示器再按全螢幕。一個有效觀戰席位就能輸出，不需要第二個觀眾連線。
8. 安裝完成後拔外網但保留區網，重開兩端、PVP／PVE／練習，確認沒有外部資源請求。沒有實際做此步就標NOT_RUN。

MAX_ROOMS預設32為資源拒絕門檻，不代表32房效能已驗證。實測基準為同時1PVP＋2練習＋1PVE及各一觀眾；若活動更多房，請依預期並行量追加測試。DATA_WARNING_MB預設512，/health顯示資料庫容量告警；主機每分鐘告警且保留成績，維護者先備份再處理。

8小時長測：啟動主機後在另一個終端執行`npx tsx tests/network-soak.ts http://localhost:3000 480 --recovery`；完整跑滿並查看evidence/network-soak-480min.json才算完成。這個脚本以真實Socket.IO連線四個混合房，循環結束再開局，每5分鐘將一個練習玩家斷線再恢復；不替代跨筆電、鏡頭與HDMI測試。詳細結果見交付的acceptance_report.md。
